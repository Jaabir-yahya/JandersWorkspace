It provides manual bookkeeping capabilities for 80% of Kenyan business owners (mama mbogas, dukas) while preparing infrastructure for the 20% who need integrations and automation.\n\n### Key Metrics\n\n| Metric | Value |\n|--------|-------|\n| Target Market | 80% manual users, 20% integration users |\n| Primary Geography | Kenya (Nairobi) |\n| Primary Currency | KES (Kenyan Shilling) |\n| Current Phase | MVP - Manual Bookkeeping |\n| Architecture | Turborepo Monorepo |\n\n### Business Model\n\n- **BASIC Tier**: Manual bookkeeping (current focus)\n- **PREMIUM Tier**: Integrations (M-Pesa, WhatsApp, QuickBooks, Xero)\n- **ENTERPRISE Tier**: Multi-store, advanced analytics\n\n---\n\n## Project Vision\n\n### Mission Statement\n\n> \"Build the ledger right for manual users.
